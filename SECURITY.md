# Security policy

## Reporting a vulnerability

Email `contact@maidepot.com` with the subject `AgentDeck security report`.

Include the affected version, operating system, reproducible steps, and expected impact. Do not include passwords, access tokens, provider credentials, private conversation content, or unrelated customer data. If sensitive evidence is necessary, ask for a protected transfer method first.

We aim to acknowledge actionable reports within three business days. Please allow time for investigation and a coordinated fix before public disclosure.

## Supported releases

Security fixes are shipped only for the current stable desktop release and the currently deployed PWA. Older desktop releases should be updated when a signed update is offered.

## Product boundary

AgentDeck does not issue Claude, ChatGPT, Codex, API, or connector credentials. Suspected compromise of a provider account must also be reported to and revoked through that provider.
