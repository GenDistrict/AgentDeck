# Support

For ordinary support, email `contact@maidepot.com` or open a GitHub issue. Never include credentials, tokens, private session transcripts, API keys, or raw account configuration.

Before reporting a problem:

1. Record the AgentDeck version and operating system.
2. Try **Reload app** once.
3. If the error repeats, try **Restart in safe mode**.
4. Export diagnostics from **Settings → Help & recovery → Save diagnostics**.
5. Open the diagnostic file and review it before sharing.

Attach only the minimum information needed to reproduce the problem. Security vulnerabilities must be reported through [SECURITY.md](SECURITY.md), not a public issue.
