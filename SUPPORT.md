# AgentDeck Support

## Choose the right channel

- **Reproducible bug or feature request without private data:** open a GitHub issue using the provided template.
- **Ordinary support that requires account-specific context:** email `contact@maidepot.com` with only the minimum necessary information.
- **Suspected vulnerability:** follow [SECURITY.md](SECURITY.md) and report it privately. Never use a public issue.

Never include passwords, access tokens, cookies, provider credentials, API keys, private session transcripts, customer data, proprietary source files, raw account configuration, or unreviewed diagnostics in GitHub Issues.

## Before reporting a problem

1. Confirm that you are using the current stable AgentDeck release.
2. Record the AgentDeck version, operating system, architecture, and affected engine or provider without including an account name or email address.
3. Try **Reload app** once.
4. If the error repeats, try **Restart in safe mode**.
5. Reproduce the problem with the smallest non-sensitive example possible.
6. If needed, export diagnostics from **Settings → Help & recovery → Save diagnostics**.
7. Open and review the diagnostic file yourself before deciding whether to share it privately with support.

Do not attach diagnostic files to a public issue. Copy only the specific redacted lines needed to explain an ordinary bug.

## What support covers

This repository covers the current stable AgentDeck desktop release, the deployed AgentDeck PWA, official installers, update metadata, and AgentDeck-operated connection services.

Claude, ChatGPT, Codex, model APIs, cloud platforms, connectors, and organization-managed gateways are third-party or customer-operated services. Subscription, billing, provider outage, account suspension, provider-side data deletion, and provider credential recovery must be handled with the relevant provider or organization administrator.

## Useful information for a public bug report

- AgentDeck version and installation platform;
- operating system and architecture;
- affected component and engine/provider type;
- whether the issue is a regression;
- minimal steps using test data;
- expected and actual behavior; and
- a screenshot only after checking it for account names, paths, conversation content, project information, and notifications.
