# AgentDeck 0.1.206

Hotfix. Changing the permission mode on a session that had not been resumed yet (right after app launch) was silently lost — the next message resumed the session with its previously saved mode, so a chip set to Auto kept reverting to Auto-approve edits. The choice is now saved immediately and the next resume starts from it.
