# AgentDeck 0.1.205

AgentDeck 0.1.205 is an urgent permission-mode hotfix for active Claude and GPT sessions. It makes the selected **Auto** mode take effect immediately, including when a tool approval is already waiting.

## Fixed

- **Auto no longer waits behind the approval it is meant to handle.** AgentDeck commits the product mode before synchronizing provider settings, so an active Claude or GPT session cannot fall back to Auto-approve edits while a card is waiting.
- **Existing safe approval cards continue immediately.** Selecting Auto re-evaluates already visible A/B actions and allows them without another click.
- **The safety boundary is unchanged.** Irreversible C-grade actions, explicit questions, and prompt-injection reviews still require a person. Transitions from unrestricted provider modes also fail closed if provider synchronization cannot be confirmed.
- **The choice survives reconnects.** The session metadata and next provider turn both carry the selected Auto mode even when the live settings update has to be retried.
