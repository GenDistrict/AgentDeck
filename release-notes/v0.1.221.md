# thread0 0.1.221

thread0 0.1.221 strengthens Remote sign-in and collaborator connections, completes the public desktop rename, and fixes several interaction details that could interrupt everyday work.

The desktop downloads are immutable, version-specific links to the artifacts served by the thread0 stable update channel.

## Highlights

- **More reliable Remote sign-in** — installed PWAs use the correct redirect flow, legacy AgentDeck-origin installations remain supported, and a first Google sign-in no longer needs a second attempt to reach the app.
- **Recovered collaborator connections** — App Check and relay recovery no longer strand a valid collaborator invitation or an already registered personal device.
- **Cleaner copied messages** — copying a response preserves useful structure without carrying theme colors or dark backgrounds into email and document editors.
- **Correct Korean IME sending** — modifier-based sending keeps the final composed Korean character and clears the composer without leaving a duplicate character behind.
- **Complete thread0 desktop identity** — newly published Windows and macOS artifacts use the thread0 installer and application names while retaining the internal identifiers required for safe upgrades from AgentDeck.
- **Hardened cross-platform release evidence** — source fingerprints are stable across LF and CRLF checkouts, macOS packaging uses the native copy shortcut, and the signed release is bound to the exact tagged source.

## Verification

The immutable 0.1.221 source fingerprint matches its pre-publication signoff.
