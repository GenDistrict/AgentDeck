# AgentDeck 0.1.203

AgentDeck 0.1.203 is a permission-mode hotfix for Claude and GPT sessions. It keeps **Auto** as Auto, applies the same risk-based approval contract to both engines, and fixes the macOS local-model dependency lookup introduced by the previous update.

## Fixed

- **Auto no longer changes to Auto-approve edits.** Claude receives the provider's neutral wire permission mode while AgentDeck retains ownership of the selected product mode.
- **Claude and GPT now follow one Auto contract.** Safe and reversible actions are approved automatically; irreversible actions and explicit questions still wait for you.
- **Auto stays effective after changing modes during a session.** The active session reads the current AgentDeck mode instead of continuing with a stale engine-specific value.
- **Known-safe transcript reflections stop raising repeated injection cards.** Exact copies of AgentDeck's own fixed harness context are recognized locally; altered copies, added instructions, and mismatched account data continue to be reviewed.
- **macOS local-model setup finds an official llama.cpp package reliably.** If the latest upstream release has incomplete platform assets, AgentDeck searches recent official releases for the matching Apple silicon package.
- **Your devices and outside developers are separated in Connections.** Persistent trusted devices no longer share one management surface with time- and role-limited guest access, and destructive phone actions sit in their own final section.

## Verification

The hotfix passed the full regression suite, packaged-app dual boot, UI screenshots, packaged button coverage, and live Claude and GPT permission tests. The live tests confirmed a safe shell action completed in Auto with zero human approval callbacks, while questions remained human decisions.
