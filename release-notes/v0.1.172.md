## Highlights

### More reliable sign-in

- Added Google sign-in to the desktop app through a secure browser handoff.
- Retried email authentication once when sending fails because of a transient network error.
- Made Codex browser-login completion poll the stored credentials and automatically recover from a stale login lock, so retrying no longer requires restarting AgentDeck.

### Correct conversation chronology

- Messages sent while an agent is streaming now remain at their original chronological position after interruption and final-response reconciliation.
- The fix applies to both Claude and Codex sessions.

### Enterprise operations

- Added AARRR funnel and reward-loop views to the enterprise administration console.
- Corrected six misleading metric paths and improved sidebar wrapping.
- Managed-chat requests for key-based OpenRouter access now direct administrators to the Enterprise organization AI connections page, where credentials are stored in Secret Manager instead of chat or transcript content.

### Lower operational overhead

- Reduced redundant user-document writes from desktop heartbeat traffic.
- Added content-blind lifecycle telemetry for operational reliability. These events contain operational metadata, not prompts, responses, tool content, or work-file contents.
