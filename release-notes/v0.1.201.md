# AgentDeck 0.1.201

AgentDeck 0.1.201 is about trust in the everyday paths: the phone app now loads and keeps your conversation history reliably, stops flashing connection banners every time you open it, and the desktop settings are reorganized around how the features are actually used. Local GGUF models grow up to multiple models per account, and finished turns suggest next actions only when the agent actually has something contextual to offer.

## Highlights

### AgentDeck Remote you can rely on

The phone app had three long-standing sources of confusion, all rebuilt from the ground up rather than patched:

- **Your history loads, and stays in order.** Opening a session mid-work could show an empty screen, or messages that arrived tangled out of order. Transcript pages are now merged deterministically — the same conversation always renders the same way, no matter which network response arrives first — and history loads even while the agent is actively streaming.
- **No more banner roulette.** Reconnecting used to flash alternating banners on every app open. There is now a single connection strip that only appears when the connection is genuinely stuck — the normal resume-reconnect every phone goes through stays silent, and the strip clears the moment you are back online.
- **Finished turns suggest less, and better.** The next-action card now only shows suggestions the agent actually made in context — never a generic frequent command. Dismissing is a first-class action that sends nothing, and you can type your own follow-up right in the card.

### Settings, reorganized

- **Same shape on desktop and phone**: Accounts → Connections → Chat → Security → Auto-run → Usage → Language → Power → Help.
- **Inviting an outside developer is now a first-class row** under Connections — it was buried inside device management.
- Icons are now one consistent stroke style throughout.

### Local models, more than one

- **Multiple GGUF models per account**, with a compatibility badge for tool-calling support, and model switching that takes effect on the next turn.
- **Choose the harness** (Claude Code or Codex) the local model runs under, with equal standing.

### Clearer moments across the app

- **Errors say whose failure they are** — a provider outage, a local server that is off, a network drop — with the next step to take, not an apology.
- **When the agent says it cannot control a browser**, a card offers connecting the Chrome you already use.
- **Switching accounts mid-session** is now an entry point on the chat header account chip, with a clear warning when switching engines would lose in-conversation context.
- **Prompt-injection findings show their evidence**: the source file or URL, the quoted original text, and the apparent intent — so your approval decision is informed, not blind.
- **Guest invites work from the first attempt** — the guest approval screen no longer stalls when opened before the desktop finishes identifying itself.
- **First-run now shows three everyday task cards** (one-time) that have each been verified end-to-end on a real machine.
