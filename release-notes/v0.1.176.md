# AgentDeck 0.1.176

AgentDeck 0.1.176 is a stable release. It fixes a startup failure on brand-new installations and carries the mobile-connection, terminal, and measurement improvements from the withdrawn 0.1.175.

The desktop downloads are immutable, version-specific links to the same artifacts served by the AgentDeck stable update channel.

## Highlights

### First launch works again on fresh installations

- Fixed a crash that made the very first screen fail to open on a brand-new installation (no existing sign-in) on both Windows and macOS. Signed-in installations were unaffected. Versions 0.1.171 through 0.1.175 contained this defect and have been withdrawn from this page; if you downloaded one of them and saw "This screen could not be opened", install 0.1.176.
- The release gate now boots every packaged build twice — once as a brand-new user and once as an existing user — and fails on any renderer error before anything is published.

### Mobile connection that heals itself

- The iOS home-screen app now recovers automatically when the system freezes an in-flight authentication refresh, instead of requiring a force-close. Returning from the background pre-warms authentication.
- The mobile terminal gained paste and copy-selection buttons, using bracketed paste so multi-line commands arrive safely.
- When a session is waiting for your response but the response card has not arrived, the app now says so and quietly re-fetches the pending list, instead of showing "loading the response card" indefinitely.

### Adoption measurement without identifiers

- The download site and desktop app feed an acquisition funnel (visit → download page → download → install) built entirely from anonymous counters; requests carry a single step name and no identifiers, accounts, versions, or IP addresses are stored.
- The desktop app distinguishes new installs from version updates so release days do not inflate install counts.
- Turn counts were added to the existing content-blind usage summary. As before, these are operational numbers — never prompts, responses, tool output, or file contents.

## Verified release status

- Windows stable channel: version 0.1.176 published with an Authenticode-signed installer, boot-verified as both a new user and an existing user.
- macOS stable channel: version 0.1.176 with a Developer ID signed, Apple-notarized, and stapled DMG.
- PWA: production bundle updated alongside the desktop release.
- Installer SHA-512 values were independently checked against the published artifacts.
