# AgentDeck 0.1.175

AgentDeck 0.1.175 is a stable release focused on mobile-connection resilience, clearer waiting states, and anonymous adoption measurement.

## Highlights

### Mobile connection that heals itself

- The iOS home-screen app now recovers automatically when the system freezes an in-flight authentication refresh. Previously this could wedge the connection until the app was force-closed; the app now detects the stall, rebuilds its authentication client, and retries — the programmatic equivalent of restarting the app, without losing your place.
- Returning to the app from the background pre-warms authentication so the first action does not wait on a cold token refresh.
- Connection-recovery buttons no longer flash on screen during a normal fast reconnect.

### Terminal on your phone

- The mobile terminal gained paste and copy-selection buttons. Pasting uses bracketed paste, so multi-line commands arrive safely instead of executing line by line.

### Honest waiting states

- When a session is waiting for your response but the response card has not arrived, the app now says so — and quietly re-fetches the pending-approval list every few seconds until the card appears — instead of showing "loading the response card" indefinitely. This also covers the case where the card was already answered on another device.

### Adoption measurement without identifiers

- The download site and desktop app now feed an acquisition funnel (visit → download page → download → install) built entirely from anonymous counters. Requests carry a single step name; no identifiers, accounts, versions, or IP addresses are stored.
- The desktop app sends a one-time anonymous install ping on first run, and distinguishes new installs from version updates so release days do not inflate install counts. What is transmitted is the step name only.
- Turn counts were added to the existing content-blind usage summary. As before, these are operational numbers — never prompts, responses, tool output, or file contents.

### Enterprise operations console

- Added per-user journey and retention views (D1/D7), a daily breakdown table with period filters, and the acquisition-funnel section.
- Operator accounts are excluded from all operational statistics.
