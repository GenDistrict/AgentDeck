# thread0 0.1.226

thread0 0.1.226 makes organization-managed AI routes usable from ordinary sessions, improves Remote session catch-up, and strengthens release reliability across Windows and macOS.

## Highlights

- **Organization AI routes in every session** — company-provided providers and their allowed models now appear alongside personal accounts in start, session, and account-switching flows, with the actual organization route shown in the header.
- **Accurate provider controls** — model and effort choices are limited to the capabilities declared for the selected personal or organization-managed route, without silently falling back to a personal Claude account.
- **Localized session actions** — rename, branch, archive, follow-up, account switching, and delete actions use the active app language instead of falling back to English.
- **Visible Remote catch-up** — reopening an active session from the PWA shows that newer messages are being synchronized, keeps cached content visible, and clears the indicator when the authoritative transcript arrives.
- **More deterministic loading states** — asynchronous connector views retain loading, data, empty, and error as separate states, and the release checks now wait for the observable state transition rather than a machine-dependent fixed delay.
- **Hardened release evidence** — live provider probes use isolated temporary identities and workspaces, clean every provider transcript and server record, and bind the release to the exact immutable source tag.
