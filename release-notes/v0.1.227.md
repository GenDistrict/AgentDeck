# thread0 0.1.227

thread0 0.1.227 updates the bundled Codex runtime and adds entitlement-aware support for OpenAI's current GPT-6 Astra and GPT Image 2 models.

## Downloads

- [Windows 10/11 x64 installer](https://storage.googleapis.com/gendistrict-agentdeck-updates/releases/0.1.227/windows/x64/thread0%20Setup%200.1.227.exe)
- [macOS 13+ Apple Silicon DMG](https://storage.googleapis.com/gendistrict-agentdeck-updates/releases/0.1.227/macos/arm64/thread0-0.1.227-arm64.dmg)
- [SHA-512 checksums](https://github.com/GenDistrict/AgentDeck/blob/v0.1.227/SHA512SUMS.txt)
- [Install guide](https://thread0.ai/download/)

The desktop downloads are immutable, version-specific links to the artifacts served by the thread0 stable update channel.

## Highlights

- **GPT-6 Astra when your account has access** — Astra appears automatically in thread0's GPT model picker as soon as the connected OpenAI account returns it, without exposing unavailable models to accounts that are still waiting for rollout.
- **Accurate Astra reasoning controls** — thread0 preserves the model's supported `low`, `medium`, `high`, `xhigh`, and `max` effort levels.
- **GPT Image 2** — OpenAI image-model discovery includes `gpt-image-2`, and OpenAI image generation uses it as the default when no model is explicitly selected.
- **Updated Codex runtime** — the bundled Codex CLI is updated to 0.153.2 so current model metadata and capabilities reach the desktop and Remote UI.
- **Provider-test cleanup** — release probes isolate and remove their temporary provider transcripts, sidecars, locks, app metadata, and server records.

## Verification

The immutable 0.1.227 source passed the complete prepublication gate: 266 regression files, type checks, production builds, behavioral model mapping and media execution tests, real Claude and Codex probes, release-signoff verification, and zero residual test sessions. Physical-device and account-entitlement scenarios remain explicitly `awaiting-user-live-validation`; they are not reported as passing.

## Availability

GPT-6 Astra is shown only after OpenAI enables it for the connected account. GPT Image 2 requires an eligible OpenAI API project. Availability is controlled by OpenAI and can differ by account and organization.

## Integrity

SHA-512 hashes for both installers are listed in [SHA512SUMS.txt](https://github.com/GenDistrict/AgentDeck/blob/v0.1.227/SHA512SUMS.txt). The Windows installer is Authenticode-signed by `MAI DEPOT, Inc`. The macOS app and DMG are Developer ID signed, Apple-notarized, stapled, and Gatekeeper-validated.
