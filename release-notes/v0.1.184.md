# AgentDeck 0.1.184

AgentDeck 0.1.184 is a stable release focused on trust during first-run onboarding: the app now tells you exactly what it found, what it can and cannot import, and what a sign-in requires — before you spend time on it.

## Highlights

### Honest onboarding on macOS

- On macOS, the Claude CLI stores its credentials in the system Keychain, so the one-click import that Windows users get is structurally impossible there. AgentDeck now detects the sign-in trace anyway and says so plainly — "we found your previous Claude sign-in, but macOS keeps it in the Keychain, so one fresh sign-in connects it" — with the sign-in button right there. No more false "nothing found".

### Know what a sign-in requires

- The sign-in waiting screen now states up front that connecting requires a paid subscription (Claude Pro/Max, or ChatGPT Plus and higher). Users without one no longer spend ten minutes in an OAuth flow that cannot finish.

### Operations console accuracy

- Timer-generated events (update checks, idle nudges) no longer count as user activity. A user who merely left the app open overnight no longer shows up as "returning".
- Daily session counts now include the first reported day of devices born inside the query window, so per-user journeys and the daily table agree for new users.
- "Account connected" now means a signed-in profile, not a profile shell created by clicking an engine button before signing in.
- Journey rows now show sign-in attempts and failures, so you can see exactly where a user got stuck.
