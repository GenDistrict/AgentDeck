# thread0 0.1.229

thread0 0.1.229 makes the phone-to-PC connection faster and harder to break, gives brand-new accounts a first screen that says what to do, and closes a handful of collaborator and Remote gaps reported by users. It contains every change since 0.1.227.

## Highlights

- **Direct connections are actually used** — a phone that starts on the relay now upgrades to the direct WebRTC path as soon as it opens, instead of staying on the relay for the whole session. On the same Wi‑Fi this removes two cloud round trips from every request.
- **Connections survive drops** — when a relay socket ends (including the hourly Cloud Run request limit) or a direct link fails while moving between Wi‑Fi and cellular, both sides rejoin the same encrypted room in about a second rather than re-pairing through signaling. The relay now tells the surviving side immediately when its peer leaves, and the phone pings every 8 seconds while the screen is on so a dead link is noticed in about 11 seconds instead of 28.
- **Much faster file transfer from the phone** — chunk requests are pipelined and, with a 0.1.228+ desktop, use 256 KB chunks on the relay. A 1 MB upload measured against a real relay with a 150 ms round trip went from 21 seconds to about 1 second. Relay messages above 1.4 MB are now split and reassembled instead of failing.
- **Less signaling** — ICE candidates are folded into the offer/answer (bounded 400 ms gather), so most pairings no longer write per-candidate documents.
- **Connection diagnostics** — Settings → Screen diagnostics in Remote shows the active transport (direct, relay, or PC server), round-trip time, and how many upgrades, fallbacks, rejoins, and replayed requests happened.
- **A first screen that says what to do** — until the first message is sent, Home shows a "connected, start here" heading, three zero-prep example tasks, and the composer, instead of a dashboard of zero tiles. Example cards fill the composer rather than sending. The "continue recent work" offer appears only when a Claude CLI login was actually found.
- **Collaborator polish** — the collaborator header actions sit at the right edge on every screen size, activity and conversation timestamps include the date, and the Remote session screen has a "New session in this project" action like the desktop.
- **Slash commands in thread0** — the composer palette lists what the Claude CLI advertises (skills such as `/code-review`, `/simplify`, `/security-review`, `/run`, `/loop`, `/schedule`, and built-ins such as `/context`, `/usage`, `/compact`, `/clear`, `/rename`, `/config`). `/model` and `/effort` now update the thread0 selectors, `/clear` clears the on-screen transcript too, and `/fast` explains that it is unavailable here and points to the model selector.
- **Relay always warm** — the thread0 relay service now keeps one instance running, so the first fallback connection after a quiet period no longer waits for a cold start.
