# AgentDeck 0.1.177

AgentDeck 0.1.177 is a stable release focused on the first-run experience and telemetry hygiene.

## Downloads

- [Windows 10/11 x64 installer](https://storage.googleapis.com/gendistrict-agentdeck-updates/releases/0.1.177/windows/x64/AgentDeck%20Setup%200.1.177.exe)
- [macOS 13+ Apple Silicon DMG](https://storage.googleapis.com/gendistrict-agentdeck-updates/releases/0.1.177/macos/arm64/AgentDeck-0.1.177-arm64.dmg)
- [SHA-512 checksums](https://github.com/GenDistrict/AgentDeck/blob/v0.1.177/SHA512SUMS.txt)

The desktop downloads are immutable, version-specific links to the same artifacts served by the AgentDeck stable update channel.

## Highlights

### A clearer first run

- The sign-in screen now explains what the account is for: one free account powers secure remote access from your phone and device pairing. Conversations are still never stored on AgentDeck servers.
- Every release build is now boot-verified twice before publishing — once as a brand-new user and once as an existing user — on both Windows and macOS.

### Honest waiting states

- When a session is waiting for your response but the response card has not arrived, the desktop app now says so and quietly re-fetches the pending list, instead of showing "loading the response card" indefinitely.

### Telemetry hygiene

- Fixed a client bug that re-uploaded the same anonymous operational events every minute after a successful upload. The server also became idempotent, so older versions that still resend cause no duplication.
- The anonymous install counter now distinguishes new installs from version updates, and release-verification boots are excluded from it.

## Verified release status

- Windows stable channel: version 0.1.177 published with an Authenticode-signed installer, boot-verified as both a new user and an existing user.
- macOS stable channel: version 0.1.177 with a Developer ID signed, Apple-notarized, and stapled DMG — boot-verified the same way in CI before publishing.
- PWA: production bundle updated alongside the desktop release.
- Installer SHA-512 values were independently checked against the published artifacts.
