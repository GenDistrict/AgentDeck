# AgentDeck 0.1.210

This release finishes the move to email-only developer invitations and closes every gap we found in a full audit of guest access enforcement, prompted by a real report: revoking a guest device did not actually cut the guest off. It also overhauls the web app's update banner, which kept reappearing when switching between PCs.

Inviting an outside developer now has exactly one flow: enter their email, they sign in with that address, and the invitation is waiting. Link, QR, and token invitations are gone end to end — the server no longer issues or redeems them, the guest entry screen and the desktop's SAS approval card are removed, and stale invitations can no longer flood the desktop with approval popups at launch. Guests who lose access now see why (expired vs. disconnected) and what to do next, within seconds.

Guest enforcement is now airtight. Revoking a guest device revokes the server-side grant and permanently prevents silent re-registration — previously the desktop would quietly re-add a revoked guest within twenty seconds. Live events pushed to guests now pass an allowlist filter, so a guest only ever receives updates for sessions shared with them; transcripts of other sessions, permission cards, the owner's device list, and login output no longer reach guest devices. Artifact downloads are scoped to shared sessions, and expired guests are refused at the authentication layer itself.

The web app's update banner had four independent triggers and only one of them knew that a centrally deployed shell has nothing to do with the connected PC's version. All triggers now funnel into a single decision that actually re-checks the deployed shell; the PC-version comparison only applies when the PC itself served the page. A stale-cache boot right after switching PCs now heals itself silently instead of showing a banner, the update check no longer grows the offline cache, and applying an update now sticks across cold launches.

## Highlights

- **Email-only developer invitations** — link/QR/token invitations removed from server and clients; invitation appears right after signing in with the invited address; no more approval-card popups from stale invitations.
- **Guest revocation is final** — revoke removes the server grant and blocks re-registration; the guest sees a clear ended screen with the reason and next step within ~20 seconds.
- **Guest event isolation** — pushed events are allowlist-filtered per guest; only shared-session updates are delivered; artifact downloads scoped; expired guests cut at the auth layer.
- **Update banner fixed** — no false banners when switching PCs or in the native app; silent self-heal on stale boots; update check no longer bloats the offline cache; applied updates persist.
- **Quality** — opening a folder that no longer exists reports an error instead of failing silently.
