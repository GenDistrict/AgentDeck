# AgentDeck 0.1.181

AgentDeck 0.1.181 is a stable release that removes the sign-in wall from the first run. You can now start working the moment the app opens — an account is only asked for where it is actually needed.

The desktop downloads are immutable, version-specific links to the same artifacts served by the AgentDeck stable update channel.

## Highlights

### Start without signing in

- The desktop app no longer shows an account gate on first launch. Pick Claude or GPT and go — the app provisions a background identity automatically.
- A full account (email or Google) is now required only for the features that need one: connecting your phone for remote access, and enterprise-managed installs.
- If you sign up later, your journey continues on the same identity — settings, devices, and history carry over instead of starting from scratch.

### Better insight into where onboarding fails

- The app now reports (anonymously) which engine was chosen and whether CLI sign-in completed or failed, so setup problems can be found and fixed instead of silently losing new users.

### Fixes

- 0.1.180 briefly shipped for Windows with a server-side mismatch that rejected the new onboarding events; the server was fixed the same day and 0.1.181 supersedes that build with the client and server verified against each other.
- New-user and existing-user journeys were verified end to end on the packaged build — from first launch through anonymous identity, device provisioning, starting a session, and a real model turn — before publishing.

## Verified release status

- Windows stable channel: version 0.1.181 published with an Authenticode-signed installer (Azure Trusted Signing), boot-verified as both a new user and an existing user.
- macOS stable channel: version 0.1.181 with a Developer ID signed, Apple-notarized, and stapled DMG — boot-verified the same way in CI before publishing.
- PWA: production bundle updated alongside the desktop release.
- Installer SHA-512 values were independently checked against the published artifacts.
