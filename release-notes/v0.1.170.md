# AgentDeck 0.1.170

AgentDeck 0.1.170 is a hotfix release for transcript ordering, zoom recovery, and automatic approval review reliability.

These are immutable, version-specific links to the same verified artifacts served by the AgentDeck stable update channel.

## Changes

- Routine successful automatic-review notices no longer flood the transcript or push the actual response upward.
- Automatic-review denials and errors remain visible at their original chronological position.
- A visible reset control appears when the desktop zoom is not 100%, making accidental zoom changes recoverable without knowing a keyboard shortcut.
- The local automatic-review classifier can handle concurrent work more reliably.

## Release status

- Windows installer: Authenticode signed and clean-VM installation verified.
- macOS DMG: Developer ID signed, Apple-notarized, stapled, and Gatekeeper-validated.
- PWA: production bundle verified as 0.1.170.
- Version 0.1.169 was not publicly released. Stable users upgrade directly from 0.1.168 to 0.1.170.
