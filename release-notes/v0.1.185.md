# AgentDeck 0.1.185

AgentDeck 0.1.185 introduces a delegation mode for AgentDeck Remote — so you can hand a device to an outside developer with clear, enforced boundaries — and hardens account, revocation and operations surfaces.

## Highlights

### Remote delegation mode

- **Folder policy.** Restrict which folders a paired device can see — an allow-list ("only these") or a block-list ("all but these"). Sessions, listings, transcripts and browsing all obey the boundary, enforced in the main process. Folders are chosen with a normal picker, not by typing paths.
- **File transfer toggle.** Turn photo/document transfer on or off per device (on by default). Turning it off blocks sending and downloading files in both directions.
- **Audit log.** Every terminal command a delegated device types, every file it sends or downloads, and every blocked attempt is recorded for you to review later on the main PC. The log cannot be read or deleted remotely.
- **Terminal and folders can't both be loose.** A folder-restricted device cannot also have terminal access — a shell can step outside any folder boundary.

### Account and revocation safety

- **AI accounts are view-only from Remote.** You can no longer add, sign in, sign out or delete AI accounts from the phone — only see their status. Account management stays on the PC.
- **Sessions can't be deleted from Remote.** Transcripts are an audit record; deletion is a PC-only action.
- **Durable device revocation.** Revoking a device is now durable — a revoked device no longer quietly comes back on the next reconnect.
- **Repeated sign-outs get an explanation.** If an account keeps getting signed out, AgentDeck now tells you the likely cause (for example, the same account signed in elsewhere on this computer) instead of just showing it logged out.

### Onboarding and hygiene

- On macOS, if a previous Claude sign-in lives in the Keychain (which can't be copied), AgentDeck says so and connects it with one fresh sign-in instead of reporting "nothing found".
- The sign-in screen states up front that a paid subscription is required, so nobody spends time in a flow that can't complete.
- The web app is now **AgentDeck Remote**, so it reads as a distinct thing (a remote for your PC) from the desktop app.
